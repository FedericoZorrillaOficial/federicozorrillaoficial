## Proyectos

### Conversor CSV a SQL con login
Herramienta que convierte archivos CSV en una base de datos SQL, con acceso protegido por login.

**Resultado:** permite migrar inventarios grandes desde Excel sin personal especializado en bases de datos.

*Laravel · Next.js · TypeScript · MariaDB · Docker · CI/CD*

[Ver en vivo](https://federicozorrillaoficial.github.io/CONVERSOR_CSV_A_SQL_CON_LOGIN) · [Repositorio](https://github.com/FedericoZorrillaOficial/CONVERSOR_CSV_A_SQL_CON_LOGIN)

### Nostradamus Trade
Bot de trading que usa la API de Binance para abrir y cerrar posiciones siguiendo un conjunto de reglas.

**Resultado:** menos tiempo de backtesting, de análisis y de pantalla frente a los gráficos.

*Rust · JavaScript · PostgreSQL · HTML · CSS*

[Ver en vivo](https://federicozorrillaoficial.github.io/NOSTRADAMUS-TRADE/) · [Repositorio](https://github.com/FedericoZorrillaOficial/NOSTRADAMUS-TRADE)

### Dona Me
Web con pasarela de pagos que acepta tarjetas de débito, crédito y PayPal, sin monto fijo.

**Resultado:** recibe donaciones de forma automática.

*React · CSS · API de PayPal*

[Ver en vivo](https://federicozorrillaoficial.github.io/DONA_ME/) · [Repositorio](https://github.com/FedericoZorrillaOficial/DONA_ME)

### FED-AI
Modelo de IA con Ollama que toma la foto y el título de un producto y genera descripciones editables.

**Resultado:** reduce de forma radical el tiempo de subir y editar productos en una tienda.

*C · PHP · HTML · CSS*

[Ver en vivo](https://federicozorrillaoficial.github.io/FED-AI) · [Repositorio](https://github.com/FedericoZorrillaOficial/FED-AI)
